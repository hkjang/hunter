# Hunter v1.8.0

에이전트 진단에 선택 검색·메모리·모델·격리 실행·관측성을 연결하고 같은 실행의 명시 재개, 추가 입력과 한국어 보고서를 제공합니다. 기본 배포는 `hunter:v1.8.0` 서비스 이미지와 일반 PostgreSQL, 기존 네 환경변수를 유지합니다. 릴리즈 첨부는 `hunter-v1.8.0.tar.gz` 한 개입니다.

## 실제 변경

- 검색 6종과 사용자·서비스별 로컬 기억, 선택 임베딩·Graphiti·설치된 pgvector 사용. 검색 자료는 비신뢰 참고이며 로컬 현재 권한을 우회하지 않습니다.
- OpenAI 호환·Anthropic·Gemini·Ollama native 스트리밍, 역할별 순차 대체와 완성 응답 커밋. 실패 조각·도구는 다음 제공자와 혼합하지 않습니다.
- 입력·일시 중지·모델 연결 대기에서 같은 실행 체크포인트를 명시 재개합니다. 원래 키·정책과 누적 호출·활성 시간을 검사합니다.
- 관리자 mTLS Docker 연결과 같은 Hunter digest 이미지의 고정 읽기 프로브. 임의 셸·자동 pull·불명 작업 중복 실행은 제공하지 않습니다.
- 암호화 메타데이터 outbox의 OTLP·Langfuse 선택 연결. 전체 프롬프트·증거를 내보내지 않으며 외부 장애와 업무 응답을 분리합니다.
- 인증된 조회 GraphQL과 실제 현재 상태의 MD·HTML·한국어 PDF 보고서. 폰트·고지는 이미지에 포함됩니다.

선택 외부 연동은 기본 꺼짐입니다. 원본 PentAGI 312파일을 바꾸지 않았고 새 코드는 Hunter 계층에서 연결했습니다. 원본 호환 대화·체크포인트 DB와 백업은 별도 접근 통제가 필요합니다.

## 확인한 검증과 한계

최종 런타임 소스의 전체 Go 검사를 실제 격리 PostgreSQL에서 `-race -count=1`로 실행해 1,002.123초에 통과했습니다. 상위 141개·하위 53개, 합계 194개가 통과했고 실패·테스트 건너뜀·race 보고는 0개입니다. 테스트 파일이 없는 패키지 3개는 별도로 구분합니다.

격리 PostgreSQL에서 모델·관측성 10개 및 하위 8개 회귀를 `-race`로 검사했습니다. GraphQL·보고서 4개 회귀도 통과했고 별도 PDF 추출기로 한국어·내장 폰트·마스킹을 확인했습니다. 모델/검색/관측 원격 서버는 내부 모의 규격으로 검사하며 실제 공급 계정·모델 판단 품질·대상 탐지율 검증이 아닙니다.

최종 프런트엔드 79개 단위 검사와 production 빌드, 실제 로컬 연동·제어 검사를 통과했습니다. 새 모델만 켠 상태에서 실행하고 입력 대기 뒤 답변을 저장한 후 명시 재개하여 같은 실행 ID로 완료했습니다. 가이드는 사용자 PDF 54쪽·관리자 PDF 87쪽, 화면 84쌍을 포함하며 세 화면 폭의 문서·폰트·링크 검사를 통과했습니다.

로컬 후보 이미지는 네 환경변수·일반 PostgreSQL·차단된 외부 통신·비특권·읽기 전용·마운트 없는 조건에서 브라우저 31개 묶음, 재시작 15개 묶음과 같은 이미지의 고정 HEAD·TLS·TCP 프로브 3종을 통과했습니다. 31개에는 신규 플랫폼 5개·자동화 10개·알림 4개가 포함됩니다. 재시작 후 같은 ID의 체크포인트를 보존하고 명시 재개한 두 실행이 완료됐으며 대기·완료 상태의 보고서를 확인했습니다. 화면 64장과 라이선스 고지 231개 파일을 확인하고 전용 자원·임시 자격 파일을 정리했습니다.

후보는 51,495,862바이트, SHA-256 `c70345fc2ddbad8e67e048162ce896b6b9ba44ff397f3edbd0671861de962a42`이며 내장 웹·API 130개 파일이 최종 소스와 일치합니다. 원격 Docker 실제 데몬의 종단 간 배포와 실제 공급 계정은 이 시험에 포함되지 않습니다. 실행 연결은 mTLS Engine 모의 서버, 고정 프로브는 같은 이미지의 실제 실행으로 나누어 검사했습니다. Graphiti의 운영 비동기 인덱싱 완료나 모델 품질을 보장하는 결과가 아닙니다.

상세한 통합·후보 결과는 [검증 기록](validation.md)에 기록합니다. 이 문서의 후보 검증은 공개 릴리즈에서 내려받은 파일 검사와 구분하며, 공개 파일의 확인 결과는 게시 후 해당 릴리즈 본문에 별도로 기록합니다.

# Hunter v1.7.0 · 담당자와 외부 업무를 연결하는 자동화

관리자가 매번 수신자를 고치고 외부 티켓을 대조하던 반복 업무를 **자동화 관리**와 **내 업무 알림**으로 연결합니다. 모든 새 자동화는 기본 비활성 상태로 시작하며 필요한 기능만 설정해 켭니다. 기존 고정 수신자 규칙과 네 환경변수·단일 이미지 배포는 유지합니다.

## 이번 버전의 변화

1. **담당자·조직·당직 수신자**: 관리자 확인 연락처와 현재 자료 권한으로 수신자를 다시 계산합니다.
2. **알림 묶음·한도**: 같은 조건의 사건을 모으고 수신자별 한도와 긴급 예외를 적용합니다.
3. **영업일 기한 예고**: 조직의 시간대·업무 요일·휴일을 반영해 유효 기한을 안내합니다.
4. **업무 확인·미확인 대응**: 지정된 개인이 내용을 확인하고 기한 이후 미확인 사건을 별도 규칙으로 전달합니다.
5. **조직 주간 요약**: 동적 사용자의 접근 범위 또는 관리자 지정 고정 주소의 조직 범위로 미조치·신규·현재 해결 상태·기한 경과를 요약합니다.
6. **전달 결과·대체 채널·보호**: 공급자 결과를 조회·서명 콜백으로 연결하고 실패 확정 시 한 단계 대체합니다.
7. **변경 영향별 검사 선택**: 서명된 실제 경로·API·구성요소·권한 변경 목록에 맞는 검사만 현재 정책으로 요청합니다.
8. **ITSM 동기화**: 외부 티켓의 담당자·기한·상태를 조회·서명 콜백으로 반영하며 로컬 수정 충돌을 보존합니다.
9. **발송 없는 모의 검사**: 보관된 사건을 현재 조건으로 대조해 예상 건수와 제외 사유를 확인합니다.
10. **본문 보존·파기**: 적격 종결 알림을 정리하면서 업무 미확인·진행 중·불명·보존 고정 건과 중복 식별 기록을 보호합니다.

기존 화면의 목록 탐색·저장 보기·입력 보호·알림 이력과 연결하고 새 API 계약은 실행 서비스의 `/api/openapi.json`에서 제공합니다. 새 관리자 메뉴는 `/admin/automation`, 개인 업무 알림은 `/personal/inbox`입니다.

## 운영 시 구분할 상태

게이트웨이 접수, 공급자 전달 결과, 사용자의 업무 확인, 팀장 승인과 취약점 해결은 별개입니다. 불명·조회 불가·결과 충돌을 실패로 추정해 자동 재발송하지 않으며 receipt가 있는 같은 전달 ID의 수동 재전송도 막습니다. 설정을 바꾸어 과거 receipt를 새로운 상태 규격으로 해석하지 않습니다.

외부 ITSM 완료만으로 발견 건을 해결하지 않습니다. 명시적인 배포 확인과 활성 옵션이 있는 경우에만 현재 정책이 허용하는 재검증을 요청합니다. 변경 규칙의 외부 반입용 프로파일은 결과 대기 건을 만들며 외부 스캐너를 자동 실행하지 않습니다.

Hunter HMAC 콜백은 사내 게이트웨이를 위한 별도 계약입니다. Git·문자·알림톡 공급자의 원래 페이로드와 서명을 그대로 받는 범용 호환 API가 아닙니다. 실제 공급 계정·단말 수신·카카오 템플릿 승인 확인은 로컬 모의 검증과 구분합니다.

## 검증과 배포 자료

실제 격리 PostgreSQL의 전체 상위 검사 106개·하위 검사 37개와 프런트엔드 단위 검사 69개를 통과했습니다. ITSM 명시 적용 보완 이후 관련 PostgreSQL race 회귀와 실제 화면 검사도 다시 통과했습니다. 최종 내장 화면의 갤러리 74종·모바일 원본 74개, 사용자·관리자 PDF와 한글 표시·문서 12화면을 확인했습니다.

최종 오프라인 후보의 브라우저 26개 검사 묶음(새 자동화 10개 포함), 재시작 13개 묶음과 화면 50장을 확인했습니다. 네 환경변수·일반 PostgreSQL·외부 통신 차단·비특권 읽기 전용 실행에서 동작했으며 검증 전용 자원과 자격 파일을 정리했습니다. 후보 아카이브는 49,993,923바이트, SHA-256은 `ec4c2b9073dddd77394c2f6bc6ccb4de7173e9c1aa7f87697ae3b93e20b2ac8e`입니다. 긴 대기는 실제 미래 시각을 확인한 뒤 격리 DB에서 대기 시각만 조정했습니다. 최종 통합 재검사와 후보·공개 아티팩트의 검증 범위 및 결과는 [검증 기록](validation.md)에서 구분합니다.

# Hunter v1.0.0 검증 기록

이 문서는 2026년 9월 11일 릴리즈 준비 과정에서 실제 실행한 검증과 범위를 기록합니다. 화면의 문서용 합성 데이터는 운영 이미지의 초기 데이터에 포함하지 않습니다.

## 자동화·브라우저 검증

| 항목 | 결과 |
| --- | --- |
| Go 정적 검사 | `go vet ./...` 통과 |
| PostgreSQL 통합·동시성 검사 | `go test -race -count=1 -json ./...` 통과: 상위 테스트 30개와 하위 테스트 6개, 실패 0개, 209.024초 |
| React 빌드 | TypeScript 검사와 Vite 프로덕션 빌드 통과 |
| 앱 경로 | 로그인 후 22개 데스크톱 경로와 새로고침 유지 확인 |
| 모바일 | 390px에서 동일한 22개 경로의 가로 넘침 없음; 로그인·승인 화면도 별도 캡처 |
| 추가 화면 | 로그인, 선택적 승인, 모든 관리자 설정 탭, 프로필 메뉴의 버전 표시 확인 |
| 브라우저 오류 | 예상하지 않은 JavaScript·HTTP 오류 0개 |
| 문서 | HTML 링크·SEO 구조·이미지·PDF 확인, 홍보·갤러리·사용자·관리자 페이지 데스크톱/모바일 확인 |

백엔드 검증에는 소유자·팀별 접근 통제, API 키의 현재 권한, 동시 키 회전, 선택적 승인, 대상·범위 정책, DNS/리다이렉트 제한, 작업 임대·취소·권한 변경, 결과 수입·중복, 재검증, 일정, 증거 암호화, OIDC, AI 스트리밍, 외부 발신의 중복 방지 등이 포함됩니다. 독립 재현의 범위와 소스는 [보안 회귀 검증 기록](security-review.md)을 참고하세요.

## 인터넷 경로가 없는 Docker 실행

`docker save`로 만든 `hunter-v1.0.0.tar.gz`를 다시 `docker load`하고, Docker의 `--internal` 네트워크에 PostgreSQL, Hunter 서버, 별도 Hunter 워커와 검증 클라이언트를 연결했습니다. 네트워크의 `Internal=true`와 서버의 기본 게이트웨이 부재를 확인했습니다.

서비스는 `hunter:v1.0.0`, UID/GID `10001:10001`, 읽기 전용 루트 파일시스템, 임시 `/tmp`, 모든 capability 제거, `no-new-privileges`로 실행했습니다. 서비스 프로세스에는 요구된 네 개의 설정 환경변수만 전달했습니다.

1. 상태 API의 버전과 초기 관리자 로그인이 정상 동작했습니다.
2. 신규 DB에서 서비스·발견 건 목록이 비어 있어 예시 데이터가 자동 생성되지 않음을 확인했습니다.
3. 별도 워커가 기본 비활성·미분류 망으로 등록된 뒤 관리자 설정으로 활성화되는 것을 확인했습니다.
4. 승인된 자체 검증 컨테이너의 `/api/health`만 범위에 넣고 실제 HTTP 진단을 실행했습니다. 지정한 망의 별도 워커가 작업을 완료했습니다.
5. 조회 권한 개인 키에는 조회 MCP 도구만 노출되었습니다. 키 회전 직후 이전 키는 거부되고 새 키는 동작했으며 폐기도 완료했습니다.
6. 서비스 컨테이너 재시작 후 로그인, 서비스 설정, 개인 시작 페이지, 자산이 보존되었습니다.
7. 같은 내부 네트워크의 Chromium에서 실제 이미지의 로그인·개인 시작 페이지·중첩 경로 새로고침·로컬 폰트·모바일 화면을 확인했습니다. 외부 자산 요청과 JavaScript 오류는 없었습니다.
8. 기존 DB에 다른 암호화 키를 전달한 별도 컨테이너는 시작을 거부하고 종료 코드 1을 반환했습니다.

압축 아카이브의 Docker manifest에는 `hunter:v1.0.0` 이미지 한 개만 포함됩니다. PostgreSQL, 외부 진단 엔진, 문서 압축 파일은 릴리즈 첨부 자산에 포함하지 않습니다. 게시된 최종 아카이브의 SHA-256은 GitHub 릴리즈 본문에서 확인합니다.

## 검증의 적용 범위

- OIDC는 서명된 토큰을 발급하는 로컬 모의 issuer로 discovery·PKCE·nonce·JWT 검증을 수행했습니다. 조직의 실제 Keycloak realm, 인증서, 프록시와 사용자 정책은 설치 환경에서 연결 확인이 필요합니다.
- AI는 OpenAI 호환 모의 스트리밍 서버로 검증했습니다. 262,144 설정 상한은 연결 모델의 실제 컨텍스트·출력 능력을 보장하지 않습니다.
- 내장 진단은 제한된 HTTP 보안 헤더 점검과 사전 정의한 합성 데이터 권한 비교입니다. 외부 스캐너는 승인된 별도 환경에서 실행하고 결과를 가져옵니다.
- 첫 버전의 목록 조회와 그에 기반한 보고서·대시보드·그래프는 권한 범위 안의 종류별 최신 5,000건으로 제한됩니다.
- 본 검증은 모든 조직의 네트워크 구성과 임의 규모의 동시 부하를 대신하지 않습니다. 실제 서비스 도입에는 관리자 가이드에 따라 사내 연결과 승인 범위를 설정합니다.
